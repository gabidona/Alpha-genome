The first step to use AlphaGenome is to obtain an API key in the website: https://deepmind.google.com/science/alphagenome/

Click on 'Get API key' link

Log in with your gmail account in GoogleCollab and paste the API key in "Secrets", the name shoud be ALPHA_GENOME_API_KEY and the key in Value

Install AlphaGenome and import libraries

Run script of interest
